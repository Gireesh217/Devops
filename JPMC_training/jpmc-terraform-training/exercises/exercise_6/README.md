# Exercise 6 (CloudFront) 

### Goal

- Create a Cloudfront distribution with OAC in S3 origin.
- The bucket should feature the following:
  - Two images
  - Allowing only connections from the distribution
- Cloudfront should feature the following:
  - Origin to the S3 bucket
  - Access control configured to the S3 bucket
  - Price class North America and/or Europe

### Considerations

- Cost Management
- Redundancy
- Security
- Tagging
